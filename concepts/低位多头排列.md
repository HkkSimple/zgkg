# 低位多头排列

## 定义
指股价在经历长期下跌或充分调整后，在相对低位区域，短期、中期、长期均线系统经过整理（[[扭一扭]]）后，形成向上发散的多头排列状态。这是趋势由弱转强、具备较大上涨潜力的关键技术形态。

## 核心特征
1.  **位置低**：发生在股价的历史相对低位或中期调整的底部区域，前期有充分的下跌或横盘消化过程。
2.  **均线有序**：经过“扭一扭”过程，短、中、长期均线由缠绕逐渐分离，形成短期在上、长期在下、向上发散的健康排列。
3.  **成交量配合**：在均线整理末期或开始发散时，常有温和放量或明显放量启动的信号。
4.  **高价值**：与高位多头排列相比，低位多头排列的安全边际更高，上涨空间更大，是[[波段交易]]和[[趋势跟踪]]者重点寻找的形态。

## 实战意义
*   **趋势启动信号**：标志着下跌趋势可能结束，新的上升趋势正在确立。
*   **核心买点区域**：是[[B类买点体系]]中重要的入场参考背景。在此形态下出现的[[B1]]、[[超级B1]]等买点信号，成功率更高。
*   **持仓依据**：形成低位多头排列后，只要股价不跌破关键均线（如黄线），可视为趋势延续，适合持仓待涨。

## 与高位多头排列的区别
| 特征 | **低位多头排列** | **高位多头排列** |
| :--- | :--- | :--- |
| **位置** | 股价相对低位，上涨初期 | 股价大幅上涨后，历史高位 |
| **风险** | 低，安全边际高 | **极高**，可能是主力出货诱多 |
| **性质** | 趋势启动，潜力大 | 趋势末端，风险聚集 |
| **策略** | 寻找买点，积极关注 | 警惕风险，规避或准备离场 |

## 注意事项
*   需要结合整体市场环境（[[活跃市值]]、[[增量资金判断与活跃市值用法]]）进行判断。
*   并非所有低位多头排列都会立刻大涨，可能伴随震荡，需有耐心。
*   一旦形成后又被破坏（如均线再度死叉、空头排列），需警惕趋势失败。
