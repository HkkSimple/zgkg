# 砖形图战法

## 核心定义
一种基于优化版砖形图（Renko Chart）的短线交易体系，其核心哲学是 **“只做转折点的绿变红”** 。该战法过滤市场噪音，将多空力量极致简化，只捕捉空头力量衰竭、多头力量启动的爆发点。

## 核心本质
赚取的不是K线单纯上涨的钱，而是 **“洗盘结束、拉升启动”的转折点爆发力** 。日线级别的绿转红信号，往往是更低级别（如60、15、5分钟）完成N型洗盘结构后的拉升启动点。

## 六步执行手册（铁律）
1.  **交易边界**：只做股价在 **[[黄线]]（主力生命线）** 之上的股票，[[黄线]]之下绝对不碰。
2.  **信号强度**：只抓 **强红反转** 。红柱实体必须吃掉前一根绿柱的 **2/3以上** ，不足则为弱反弹，放弃。
3.  **入场时机**：
    - **当日尾盘买**：收盘前10分钟，符合条件即买入。
    - **次日早盘买**：高开 **4%以上直接放弃** ，绝不追高。
4.  **仓位管理**：无论资金大小，永远分 **2个仓** ，每天最多买 **2个票** ，以稳定心态、分散风险。
5.  **止损止盈**：
    - **止损**：以买入K线的最低价为止损位，跌破无条件卖出。
    - **持仓周期**：买入日为T日，最多持有至T+2日（共2根K线）。若期间无向上爆发力，无论盈亏，必走。
    - **止盈**：超短线无固定止盈点，有盈利即可分批卖出，新手建议盈利3%-5%即可落袋。
6.  **进阶持仓**：若买入后快速脱离成本区5%以上，可最多持仓 **4-6天** ，但此为进阶规则，新手慎用。

## 心法口诀
1.  **我要赚钱**：目标纯粹，只赚策略内的钱，不贪不惧。
2.  **不给就走**：市场不给爆发力，立即离场，不抱幻想。
3.  （根据原文补充）**执行大于技术**：严格按规则操作，克服主观臆断。
4.  （根据原文补充）**避免完美主义**：接受策略内的失败，追求长期概率优势。
