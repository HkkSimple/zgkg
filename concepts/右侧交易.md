# 右侧交易

## 核心定义
在股价趋势已经明确形成后，顺势进行买入操作的交易策略。其核心是 **“不猜底，不逃顶”** ，等待趋势确认后介入，追求赚取趋势中间最确定的一段利润。

## 核心原则
1.  **趋势确认**：必须等待下跌趋势结束、上涨趋势得到技术面确认（如关键均线拐头向上、突破重要压力位、出现[[B1]]等反转信号）后再入场。
2.  **顺势而为**：只参与已经形成[[多头排列]]、处于明确上涨趋势（[[N型结构]]）的股票。
3.  **严格止损**：一旦买入后趋势未延续反而破位（如跌破启动阳线或关键均线），必须立即止损离场，绝不“越跌越买”。

## 常见误区纠正
- **高位“越跌越买”不是右侧交易**：在周线/日线大周期仍处于相对高位时，跌破趋势线后的补仓行为是逆势操作，是导致深套的主要原因。右侧交易在此情境下的正确做法是 **破位即走**。

## 与左侧交易对比
| 特征 | 左侧交易 | 右侧交易 |
| :--- | :--- | :--- |
| **介入时机** | 趋势未反转，下跌末期 | 趋势已确认，上涨初期 |
| **核心逻辑** | 价值回归，输时间不输钱 | 趋势跟随，赚取趋势利润 |
| **风险特征** | 可能承受长期盘整或继续阴跌 | 可能买在次高点，需严格止损 |
| **心态要求** | 极高耐心，长期视角 | 纪律性强，果断执行 |
| **适合人群** | 资金量大，研究深，有耐心的投资者 | 大多数趋势交易者，尤其是新手 |
