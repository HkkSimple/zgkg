# 挖坑与填坑

## 核心定义
一套基于“**黄金坑**”形态识别与操作的交易战法总称。其核心是识别主力通过制造恐慌下跌（挖坑）完成筹码交换，并在趋势修复（填坑）过程中获取利润。根据“坑”的规模与性质，衍生出不同的应对策略。

## 何为“黄金坑”？三大必要条件
1.  **有前史 (High)**：曾经有过明确的历史高点或辉煌期。
2.  **有惨烈 (Pain)**：经历了长时间、大幅度的下跌，制造了足够的恐慌和绝望。
3.  **有企稳 (Support)**：下跌后不再创新低，开始横盘或走出温和的上升走势，表明有新资金（如“麒麟会”）进场收集筹码。

## 三类“坑”与对应战法
| 类型 | 形态特征 | 对应战法 | 核心逻辑与操作 |
| :--- | :--- | :--- | :--- |
| **大坑** | 时间跨度长，跌幅巨大（腰斩再腰斩），但基本面逻辑未死。 | **信仰之战，长线持有** | 确认主力开始填坑（突破关键颈线）后，无视中间震荡，长期持有。使用“祖宗之法”计算第一目标价。 |
| **小坑** | 在大趋势向上过程中（填大坑途中）的阶段性回撤，不破前低。 | **[[少妇战法 1.0]] / 填坑战法** | 在回调中寻找[[B1]]买点进场，不破BBI则持有，填坑至前高或跌破趋势线时卖出，赚取波段利润。 |
| **小洞 (Little Hole)** | 处于连续N型上升趋势中，因突发黑天鹅事件产生的“单针探底”。 | **一夜情战法 / 虎口夺食** | 视为“主力也被套的自救行为”，在出现长下影线时果断进场，**只做次日的一根反弹**，反弹即走，不与股票产生感情。 |

## “祖宗之法”：主力目标价计算公式
**第一目标价 = (坑沿价格 - 坑底最低价) + 坑沿价格**
- **坑沿（颈线位）**：大坑的起跌点或长期盘整箱体顶部。
- **坑底**：挖坑过程中的最低价。
- **逻辑**：主力为覆盖建仓的时间与资金成本，通常需要做出约一倍于“坑深”的上涨空间。

## 关键细节与心法
1.  **拒绝“假坑”**：三种不能碰的“坑”——（1）未开始填坑的无底洞（高点降低、低点创新低）；（2）基本面完全不了解的盲盒；（3）不属于当前主线题材的“孤魂野鬼”。
2.  **完美图形模式**：
    - **大坑套中坑，且已填完中型坑**：回调不破前低，第三次向下破位（B3）常是诱空买点。
    - **填大坑过程中的完美N型结构**：回踩低点不破前低，可计算前高为目标。
    - **出坑后的“回踩确认”**：突破颈线后缩量回踩不破，是经典的B1买点。
3.  **“破位”与“假摔”的博弈**：在坑口位置，缩量的恐怖破位往往是主力最后的清洗，构成高盈亏比的买点（B3）。
4.  **长期主义视角**：结合历史周期（如白酒2012年后的大坑）看待当前调整，具备穿越周期的眼光。
