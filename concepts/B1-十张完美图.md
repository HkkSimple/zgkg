# B1-十张完美图

## 概念定义
“B1-十张完美图”是一份系统化的图表学习资料，通过十个经典案例，将 [[B1]] 买点的核心逻辑与实战形态进行可视化、标准化呈现。它旨在帮助交易者建立对“完美一”、“完美二”、“完美三”三种标准图形的肌肉记忆，是掌握 [[B类买点体系]] 基础环节的关键训练素材。

## 核心内容
### 完美一：标准缩量回调与精准指标型图形
核心特征为“**放量启动-顶部无量-缩量至地量-小阴小阳企稳**”，且关键指标（如KDJ“勾到大负值”、[[黄线]]支撑）精准匹配。是B1最基础、最标准的模板。
- **案例1：华纳药厂**：标准三阶段（启动-洗盘-买点）范本，强调“地量 + 小阴小阳”后的耐心等待。
- **案例2：宁波韵升**：“缩量极致化”案例，验证“缩量越极致，启动越迅速”的规律。
- **案例3：微芯生物**：“大幅值勾回”案例，展示指标、量能、K线的三重共振。
- **案例4：方正科技**：“长周期建仓 + 缩量杀跌”案例，适配不同建仓时长的标的。

### 完美二：变量型洗盘与时间换空间图形
是“完美一”的灵活变形，核心特征为“**非极致缩量 + 时间换空间 + 洗盘方式多样化**”，更注重[[黄线]]支撑与分歧消化。
- **案例5：澄天伟业**：“一波流”走势，黄线不破，通过短期横盘实现“时间换空间”。
- **案例6：国轩高科**：“时间换空间”标杆，洗盘时长与前期涨幅正相关。
- **案例7：野马电池**：“指标模糊化”案例，强调“量能优先于绝对指标”。
- **案例8：光电股份**：“浅度洗盘”代表，逻辑是“浮盈少-洗盘浅”，易引发误判。

### 完美三：横盘压缩结构与红肥绿瘦图形
更复杂的启动图形，核心特征为“**异动后箱体横盘 + 红肥绿瘦 + 主力高控盘**”，本质是[[N型结构]]的横盘压缩。
- **案例9：新瀚新材**：高控盘典范，展示“窄幅震荡”、“红肥绿瘦”、“精准控盘”等特征。
