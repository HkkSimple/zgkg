# 纯血与混血

## 核心定义
“纯血”与“混血”是用于区分牛市板块炒作中不同性质标的的比喻，是构建[[曼城阵容]]和把握[[牛市ETF躺平策略]]的重要概念。
- **纯血标的**：指在某个主题或赛道中，**业务纯粹、业绩确定、行业地位稳固、被机构广泛认可**的核心公司。它们是板块的“压舱石”和“价值锚”。
- **混血标的**：指在热门主题中，**概念沾边、故事性强、弹性大但业绩支撑相对较弱**的公司。它们是板块的“情绪先锋”和“空间开拓者”。

## 特征与角色
| 特征 | 纯血标的 | 混血标的 |
| :--- | :--- | :--- |
| **业务相关性** | 核心主业，高度相关 | 业务沾边，或有转型故事 |
| **业绩确定性** | 强，有扎实基本面支撑 | 弱，主要靠预期和想象 |
| **机构偏好** | 高，是配置型资金的首选 | 低，游资和短线资金偏好 |
| **波动性** | 相对较低，走势稳健 | 非常高，涨跌迅猛 |
| **市场角色** | **稳收益**：行情中后期发力，赚取确定性收益。 | **拉空间**：行情初期冲锋，打开板块估值和想象空间。 |

## 牛市中的炒作规律
1.  **先混血，后纯血**：牛市主题行情通常始于“混血”标的的疯狂炒作，它们用连续涨停打开整个板块的上涨空间和市场关注度。
2.  **混血搭台，纯血唱戏**：当混血标的将板块热度炒高后，资金会流向有业绩支撑的“纯血”标的，完成估值修复和趋势主升。
3.  **搭配使用**：理想配置是 **“纯血打底，混血增强”**。用纯血标的确保组合底线和稳健收益，用部分仓位参与混血标的博取更高弹性。

## 操作要点
- **纯血标的**：适合作为底仓长期持有或波段操作，采用[[移动止盈]]策略，看重的是趋势的持续性。
- **混血标的**：只能作为短线或波段投机，必须设定严格的止损（如[[只输一根K线]]），且不宜重仓。炒作末期需果断离场，切勿当成价值投资长期持有。
