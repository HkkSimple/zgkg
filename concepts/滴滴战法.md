# 滴滴战法

## 核心定义
“滴滴战法”是一种**移动止盈策略**，旨在解决交易者“卖飞”和“坐过山车”两大痛点。其核心是通过极简的规则，让持仓者在趋势中“钉”住利润，在趋势反转时果断离场，确保吃下波段利润的“鱼身”。

## 操作规则
1.  **入场后**：每天收盘前进行检查。
2.  **参照物**：以**前一天的最低价（Low）** 作为当日的防守线。
3.  **判定与执行**：
    - 若**今日收盘价 > 昨日最低价**，则继续持有，心中默念“滴”。
    - 若**今日收盘价 < 昨日最低价**，则无条件卖出（“拍掉”）。
4.  **循环**：只要收盘价不跌破前一日最低点，就持续持有（“滴、滴、滴”），直到破位卖出。

## 核心逻辑与哲学
1.  **为“留下来”服务**：该战法首要目标是帮助心态不稳的交易者能够留在趋势中，避免因小幅波动而提前下车。
2.  **不追求卖在最高点**：承认无法卖在最高点是神做的事，目标是捕获确定性的波段利润。
3.  **绝对不亏钱**：通过移动止盈锁定利润，确保一笔成功的交易最终不会由盈转亏。
4.  **简化决策**：将复杂的趋势判断简化为“比大小”，交易者无需预测明天涨跌，只需严格执行今日规则。

## 适用场景
- 右侧趋势跟踪。
- 短线爆发后的利润锁定。
- 任何让交易者心里没底、容易提前卖出的持仓。

## 优缺点
- **优点**：规则简单，易于执行；能有效锁定利润，避免大幅回撤；极大缓解持仓焦虑。
- **缺点**：在加速上涨的末期可能“卖飞”，错过最后一段利润；在震荡市中可能频繁触发卖出信号。
