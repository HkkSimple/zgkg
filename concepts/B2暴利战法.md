# B2暴利战法

## 核心定义
B2暴利战法是[[B类买点体系]]中的核心组成部分，特指在B1（阶段性低点）出现后，用于**确认趋势反转或启动**的那根**放量中长阳线（B2）**的交易方法。它并非孤立使用，而是B1→B2→B3“三件套”确认链条中的关键一环，旨在捕捉主升浪的起点，提升资金效率。

## 核心逻辑与铁律
B2是给B1“盖章”的确认信号。其有效性必须满足以下五条经过历史回测的“铁律”，缺一不可：
1.  **必须在B1之后**：KDJ的J值必须已从低点（<13）**拐头向上**。
2.  **涨幅≥4%**：当日涨幅必须大于等于4%，这是主力发力与否的力度门槛。
3.  **比前一日放量**：成交量需大于前一日，代表资金真实进场。
4.  **J值 < 55**：（核心心法）B2出现时，KDJ的J值必须小于55。这表明盘面清洗干净，上涨动能充足，后续空间大。J值过高（>55）则意味着短期透支，易回调。
5.  **无长上影线最好**：光头阳线或上影线极短为佳，表明主力拉升决心坚决，不想给散户过多跟风或出逃机会。

## 三大暴力图形（高爆发形态）
在满足上述铁律的基础上，出现以下三种图形，往往意味着爆发力极强：
1.  **平行重炮（双枪战法）**：在相对平行的价格位置，连续出现两根或以上的放量长阳（涨幅常≥6%），显示主力“只买不卖”的强控盘意图，志在高远。
2.  **灾后重建**：股价连续上涨后出现缩量急跌（“灾”），精准回踩关键支撑线（如[[双线战法]]中的黄线）后，迅速拉出放量中长阳（B2）确认反转。这是连续拉升前最后的极限买点。
3.  **跃跃欲试（红肥绿瘦）**：在横盘整理期间，呈现“阳线多且实体长，阴线少且实体短”的“红肥绿瘦”量价结构。期间出现多次放量试盘阳线，根据“事不过三”经验，第三、四次放量突破往往是真启动信号。

## 操作纪律
- **买入时机**：严格在符合“五条铁律”的B2阳线出现时介入。
- **持有与卖出**：
    *   B2买入后，**2个交易日内必须出现拉升**，否则应考虑减仓或退出。
    *   止损点通常设在产生B1的N型结构的低点，一旦跌破需坚决离场。
    *   后续可结合[[双线战法]]或[[B3]]信号持有，让利润奔跑。
