# 我玩王者荣耀怎么了？一个财经主播的熊市生存告白与交易哲学

现在是2026年3月22日深夜，窗外的天已经全黑了。屏幕上飘着28000条弹幕，我手里夹着烟，刚看完第17条骂我玩王者荣耀的留言。

我突然想起前几年那波牛市，我攥着宁子的筹码从12块拿到21块，翻了快两倍的时候，没人骂我不务正业；2025年1月我提迈巴赫的那天，直播间刷了1000条恭喜，没人说我飘了。

今天就因为有人翻到我三个月玩了四场王者荣耀的记录，就有100多个人跳出来说我不务正业，说我亏了他们的钱。我就想问一句：你进股市是来挣钱的，还是来监督我玩不玩游戏的？

## 幸存者偏差？不，这是用血换回来的交易纪律

我做交易12年，亏过的钱比你们绝大多数人这辈子见过的钱都多。

2018年那波熊市，我的现金流一周之内蒸发了三分之二。那天凌晨三点我坐在电脑前，看着满屏的绿色K线，点燃了第三根烟，烟灰掉在键盘上我都没察觉。就是那次之后我明白一个道理：**这个市场里，活着比什么都重要。**

现在直播间总有人说那些晒盈利单的都是幸存者偏差，我给你算个账：上周我看了47张交割单，全是严格按照B1放飞、跌破黄线卖出的标准操作，平均每单盈利17%，最多的一单赚了43%。你告诉我这叫幸存者偏差？47个幸存者？这种偏差我希望你每天都能遇到。

给你们看个典型的：上周有个粉丝发的交割单，XX的标的，B1放飞之后阶梯量出货，跌破黄线立刻清仓，整个操作一气呵成，最后赚了29%。他说这是他第一次严格按照纪律做单，之前最多赚5%就跑了，亏起来能套30%。这不是什么神迹，就是把最简单的规则执行到极致。

## 战法的本质：把不确定的行情，变成确定的动作

很多人总问我，这个战法到底灵不灵？有没有可能失效？我给你拆解下最核心的三条规则，你照着做，就算赚不到大钱，也绝对不会亏到销户：

- **B1买入规则**：白线在黄线上方，量能连续三天放大，突破前期压力位的时候进场，仓位控制在3成以内，买的时候就把止损位设在黄线下方2个点
- **持有规则**：只要白线一直在黄线上方，只要没有出现阶梯式放量出货的迹象，就拿着，浮盈10%之后可以把止损线上移到成本位，确保不会亏本金
- **卖出规则**：两种情况必须卖，一是跌破黄线立刻走，不要等反弹，不要抱有幻想；二是出现S1信号，量能突然放大3倍以上，价格滞涨，立刻止盈

去年12月有个粉丝找我，说跟着直播做了两个月，第一次赚了点钱，后来看到B1信号之后直接满仓加了砖形图，没按照两天的纪律走，现在标的已经连续跌了7天，彻底击穿了所有支撑位，问我怎么办。我能怎么办？我只能说要么你仓位轻就拿着当学费，要么仓位重就割肉止损，下次记住规则。你要知道，我把这些规则讲得这么细，不是为了让你觉得我厉害，是因为这些都是我当年亏了几百万换回来的教训。我不希望你们再走我走过的弯路。

## 反面教材：那些败给人性的交易

还有个粉丝给我发私信，说本月回撤了6%，特别愧疚，觉得对不起我。我当时就笑了，我说兄弟，大盘这半个月跌了12%，你只回撤6%，已经跑赢了90%的人，有什么好愧疚的？他说主要问题在于该止损的时候没果断割掉，年后有个标的跌破黄线了，他想着再等等反弹，结果套了15%；3月19号恐慌性下跌的时候，他又想在周五前降仓位，结果卖在了涨停前一天，少赚了8个点。

你看，90%的亏损不是因为行情不好，是因为你管不住自己的手。我见过太多人了，买的时候拍脑袋，卖的时候拍大腿，亏了拍桌子骂娘。就是不愿意承认，是自己没有执行交易纪律。

还有个粉丝的留言我印象特别深，他说："我21年毕业就入市，最近一年才跟着B1战法操作，这不到一年经历了太多，经常在某个时刻顿悟。现在最大的变化是能看懂大势，能站在机构的角度思考问题，但还是经常管不住手，需要继续打磨。"我特别理解这种感受，我当年也是这么过来的。谁没亏过钱？谁没后悔过？交易本身就是反人性的，你要做的就是和自己的本能对抗。觉得管不住手的，就把仓位降到你亏了也不心疼的程度，拿模拟盘练没用，真金白银放进去，疼一次你就记住了。实在练不出来的，销户走人，别跟人性较劲，不是所有人都适合吃交易这碗饭。

## 被网暴的这一周：我为什么要跟黑子浪费时间

上周日我就跟大家说，我感觉非常不好，活跃市值这块要做加速的话，机构往下砸一波的胆量还是大大的有。结果这周大盘跌了5天，3000多只票下跌，我的后台炸了。有骂我预测不准的，有说我是骗子的，还有人翻出来我玩王者荣耀的截图，说我天天玩游戏不务正业，所以才亏了钱。

我当时就想笑，我从去年12月到今年2月，整整三个月就玩了四场王者荣耀，平均一个月玩不到两次，这就叫不务正业？我下播之后玩两把游戏怎么了？我碍着你挣钱了？

说实话，干我们这行，被黑是常态。你说对了，有人说你是蒙的；你说错了，有人骂你是骗子。你分享干货，有人说你要割韭菜；你免费直播，有人说你别有所图。我以前也生气，也想跟人对线，后来我想通了：你永远叫不醒一个装睡的人。他要黑你，总能找到角度。我要是跟每个黑子都对线，我每天啥也不用干了。

## 认知鸿沟：一楼和二楼的差距到底在哪

我经常在想一个问题：为什么同样的内容，二楼的粉丝听完就能执行，就能赚钱，一楼的很多粉丝听完反而亏了钱？不是我藏着掖着，是认知的差距摆在这。

二楼的粉丝系统学过整个战法体系，知道什么叫跌破黄线卖，什么叫击穿对手盘扛一天，知道什么是B1什么是S1，知道整个交易的逻辑链条。但是一楼的很多粉丝，可能连黄线是什么都不知道，你跟他说跌破黄线卖，他问你黄线在哪；你跟他说空头区间不要抄底，他问你什么是空头区间。

我要是说的太细，不合规；我要是说的太粗，听不懂的人就会骂你。上周我跟大家说煤炭涨高了该放飞该卖，有人就断章取义说我让大家清仓煤炭，结果这周煤炭回调了，他跑过来骂我，说听我的卖了煤炭少赚了多。我明明说的是底仓不动，涨高的部分该止盈止盈，他只听到"卖"这一个字。我要是说下周看多，中间有个N型回调，他又会说你不是说看多吗，怎么跌了？我不可能次次都对，也不可能每次都精准到小数点后两位，我能给你的只是一个大的方向和区间，具体的操作需要你自己结合战法去判断。

## 给所有交易者的5条生存法则

今天我把压箱底的5条交易规则说给你们听，拿纸笔记下来，下次再亏了钱，拿出来看看：

### 1. 任何一笔交易，都要有清晰的交易策略

不管你是做B1、B2、B3，还是砖形图，每套战法都有对应的严格交易规则。你买之前就要想清楚：

- 买点是什么？为什么在这个位置买？
- 卖点是什么？到了什么位置必须止盈？
- 止损是什么？跌破了哪个位置必须割肉？

很多人买的时候稀里糊涂，听别人说这个票好就买了，涨了不知道为什么涨，跌了不知道为什么跌，套住了就死扛，最后亏的一塌糊涂。上周日我就跟大家说活跃市值可能要加速下跌，你要是听进去了，减了仓，这礼拜的下跌你根本就不会受伤，心态也不会崩，下波行情起来你还能抄底。

### 2. 不要高估自己的持股能力，长线是信仰不是赌博

我常说你们不是我，我这次回撤也比较大，但我有名字对冲，我能扛，你们不一定能扛。很多人听我说长线持有，就不管什么票都拿着不动，跌了20%还在那扛，说我是做长线的。

我告诉你，长线持有是有前提的：

- 你买的票基本面过硬，行业逻辑没问题
- 你对这个公司有足够的信仰，跌30%你也睡得着觉
- 你的仓位是对冲的，不是单吊一只票

我自己的曼城阵容是低波红利、煤炭、白酒、券商、特高压、宁子、有色，基本都是对冲关系，这波下跌基本都是炮弹坑或者对冲，防守做的足够好。你要是单吊一只票，跌30%你试试？你心态早就崩了。

还有人拿宁子举例子，说我之前说宁子能到35，现在怎么不说了。我今天把话撂这：宁子你们12到15的成本，现在21，普遍都赚了三五十，多的赚了60%，该走就走，跟我没关系。以后别说我让你们拿宁子到35，跌了又来骂我。我吃一堑长一智，以后再也不推荐任何票。长线票要么你就信仰到底，下跌的时候别逼逼；要么你就做右侧，破了止损立刻走。别涨的时候说自己是价值投资，跌的时候骂娘。

### 3. 空头区间，活下去比什么都重要

现在这个位置就是空头区间，我把话放这：下礼拜如果继续向下加速，是正常的，是合理的；如果有反弹，也是弱势反弹，手里的烂票趁反弹赶紧走。你最好的赚钱机会一定是下一波多头区间，不是在这个位置瞎折腾。

很多人现在亏了30%，就想在这个位置加仓做T摊薄成本，我告诉你，你再加仓，很可能亏50%。顶和底的活留给机构去干，你屁股多大就穿多大裤衩，机构屁股大，人家能扛，你扛不住。你打开米尔的K线看看，跌破黄线之后，白线在黄线之下的时候，每一次反弹都是逃跑的机会，每一次下跌都是雪上加霜。记住：**散户永远不要抄底，不要接下落的飞刀。**

### 4. 市场永远是对的，不要跟它较劲

我知道你们很多人这波亏的很难受，这次和4月7号那次不一样，那次是一天跌完给个痛快，这次是从春节前就开始阴跌，跌了快两个月，外围还全是利空，美国和伊朗都在升级冲突，感觉看不到希望。

我问你，牛市结束了吗？如果你认为泱泱大国的牛市就这么结束了，那你现在就清仓销户，这辈子别进股市。如果你认为还没结束，那现在这点下跌算什么？市场永远是对的，错的只有你自己。你亏了钱，不要骂市场，不要骂主力，不要骂我，多想想自己为什么没有执行交易纪律，为什么跌破黄线的时候没有走。我上周就跟大家说，战争从闪电战转成持久战的时候，这一周很重要，恐慌来了机构肯定会往下砸，你要是听进去了，早就减仓了。

### 5. 交易没有标准答案，适合自己的才是最好的

金刚经说"法尚应舍，何况非法"，做股票也好，做人也好，根本就没有标准答案。很多人总想寻找一一个万能公式，按照这个公式做就能100%赚钱，我告诉你，不存在的。你看网上那些动不动上百万播放的视频，说什么"一招抓涨停""永远不亏钱的战法"，都是骗傻子的。要是真有这么好的方法，他早就自己闷声发大财了，还会告诉你？

60日线是不是最后的离场点？对于没有基础的散户来说，是，你记住跌破60日线就走，至少不会亏大钱。但对于有基础的人来说，跌破60日线可能是黄金坑，是加仓的机会。交易是活的，不是死的。你要做的是找到适合自己的交易体系，而不是照搬别人的方法。
